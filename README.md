# Little Sums

PC 端数学练习游戏，含圆点与数字显示、随机冒险和本地神经语音。界面按电脑屏幕设计，保持左右双栏和大图案，不提供手机布局。

需要 Node.js 20.19 或更新版本。在项目目录运行：

```sh
npm ci
npm run setup:voice
npm run dev
```

打开 http://127.0.0.1:5173。首次安装会下载约 310 MB 的语音模型；安装脚本会核对固定版本和 SHA-256。之后启动、合成及播放朗读都不需要连接语音服务，也不需要 API Key。

语音使用 [Kokoro](https://github.com/hexgrad/kokoro/tree/main/kokoro.js)，在服务端 CPU 上运行完整精度模型。默认是 Heart 美式英语女声（`af_heart`），语速为 `0.9`。浏览器只播放服务端生成的 WAV，不调用浏览器或系统的 TTS。前端会预取当前题目和答案；服务端默认保留最多 384 个音频文件，管理员可调整此限制，重复朗读无需重新合成。

如需更换声音或语速，重启服务时设置：

```sh
TTS_VOICE=af_bella TTS_SPEED=0.95 npm run dev
```

模型存放在 `.models/kokoro/`，音频缓存在 `.cache/speech/`，这些文件和 `node_modules/` 都不进入 Git。复制项目到另一台 PC 后重新运行上述安装命令即可；也可以一起复制模型目录，以免再次下载。

每次冒险完成后，宝物会带着闪光飞入海盗宝箱，宝箱打开并弹跳，收藏格高亮。播放简短庆祝旋律后自动开始新冒险；被怪物吃掉后播放轻快的悲伤旋律，再自动重新出发。静音会立即停止旋律，游戏不会卡住。尊重系统的减少动态效果设置。Easy 获得 Classic 宝物，Medium 获得 Silver 宝物，Hard 获得 Golden 宝物；不同等级分别叠放，已有收藏保留原等级。切换难度会从起点开始新的冒险。

游戏主画面以图形为主：加减法用 `+`、`−`、`±` 大按钮切换，星级和数字表示难度，圆点图标／`12` 切换圆点与数字。点击绿色播放按钮开始、喇叭按钮朗读，笑脸表示答对、回转箭头表示重试。冒险场景、海盗宝箱和收藏图案放大，同类宝物只显示数量；档案与管理弹窗保留家长需要的文字。

难度默认选择 `✦ · 50` 自适应练习，从 5 以内基础题开始，在 50 以内按连续难度评分选题。系统分别了解加法、减法、进位、借位，以及圆点和数字模式的表现；每 10 题穿插 6 道常规题、3 道薄弱点题和 1 道挑战题，没有已识别薄弱点时用常规题补足。混合练习每 10 题加减法各 5 题，最近 5 道题不会原样重复或仅交换加数。加零、减零的难度评分不会因数字超过 5 而继续升高；含零题（包括答案为零）通常每 5 题最多 1 道，已识别的零运算薄弱点可额外安排针对练习。首次答错降低难度；首次答对且有效思考时间不超过同类题个人基线的 1.25 倍后逐渐加难，至少积累 5 个可比较的正确用时才使用速度。重试后答对不提高首次正确率。朗读、等待音频、反馈动画、弹窗和后台停留不计入思考时间，没有倒计时。

玩家菜单中的 **Learning progress** 显示尝试题数、首次正确率、重试恢复、答案揭示、分技能速度和数字模式表现，以及薄弱点练习建议。技能正确率来自最近 20 题，数字特征正确率为累计统计；样本不足时显示正在了解表现。`★ · 10`、`★★ · 20`、`★★★ · 50` 保留固定范围随机出题，也会记录表现。自动调难度不会重置冒险，自适应宝物等级取本轮已作答题目等级的最低值；手动切换难度仍会开始新冒险。

学习记录保存到玩家自己的服务端档案；最近 200 题保留明细，更早的记录保留累计统计和去重凭据。离线时浏览器保留绑定原账号的待存记录并继续练习，重新联网或点击 **Retry saving progress** 后重试；浏览器同时缓存已保存的学习画像。切换账号重新开始题目和冒险并恢复该玩家保存的游戏设置，旧账号待存记录不会写入新账号。游客学习画像仅保留本次访问，注册和登录不会迁入游客记录。规则权重和阈值集中在 `learning.js` 的 `LEARNING_RULES` 中；这套功能用于按练习表现调整题目，学习效果需结合后续使用观察。

Dots 模式按每个数分别显示：1–10 显示圆点，0 和大于 10 的数显示数字，例如 `7 + 12` 中 7 显示圆点、12 显示数字。数字模式始终显示数字。Dots 模式答对后会翻转为数字算式，朗读完再等待 2 秒，然后恢复题目的圆点／数字显示。静音会停止朗读与音效。朗读失败时会显示重试提示，游戏仍能继续。

点击顶部的头像按钮可创建玩家档案（昵称、用户名和至少 8 位的密码）或登录已有玩家。登录状态保留 30 天；登出会撤销当前会话。登录后获得的每件宝物都会保存到该玩家自己的宝箱，刷新页面、重新登录或重启服务后仍能查看。冒险面板中海盗宝箱下方始终显示收藏格，点击宝箱还可打开完整收藏；同类宝物合并展示，数量显示在图案上方。游客也可玩，但游客宝物仅保留在本次页面访问中，不会转入玩家档案。

加法／减法／混合、圆点／数字、静音和难度选择会自动保存。登录玩家的设置保存在自己的服务端档案中，关闭网页后重新打开、重新登录或在另一台设备登录同一服务器上的同一账号，都会恢复这些选择；切换账号会使用各自的设置，难度不会再强制重置为自适应。游客设置保存在当前浏览器，关闭页面再打开仍保留；创建新档案时会带入当前设置，已有账号登录时恢复该账号的设置。暂时离线时，变更会先保留在浏览器并绑定原玩家，重新联网或在玩家菜单点击 **Retry saving game settings** 后重试；未同步的变更需要原浏览器联网保存后，其他设备才能看到。每次只更新实际改变的设置项，避免覆盖其他设备上未修改的选择。清除浏览器数据会移除游客设置和未保存的变更，服务端已保存的玩家设置不受影响。

登录后打开玩家菜单，点击 **Edit profile** 可修改昵称、登录用户名，选择 8 种插画头像之一，或上传自己的 JPG／PNG／WebP 照片（最多 10 MB）。照片可拖动、缩放及调整水平／垂直位置，预览方形裁剪结果；只保存最终 256×256 头像，服务端重新解码、移除照片元数据，不保存原图。还可设置／清除可选的生日。生日必须是有效日期，不能在未来；修改用户名后，下次登录使用新用户名。点击 **Save changes** 保存，**Cancel** 放弃本次修改。旧档案自动显示默认的泰迪熊头像；编辑不会影响密码或宝物收藏。

玩家昵称、头像、生日、游戏设置、密码哈希、会话及宝物数量保存在服务端 `.data/players.json`，不进入 Git，也不能通过静态文件 URL 下载。写入按顺序执行并原子替换文件；重复提交同一宝物领取记录不会重复计数。网络暂时不可用时，待保存记录会留在浏览器中，可点击 **Retry saving** 重试，或等待重新联网后自动重试；记录始终绑定原玩家。密码使用独立盐的 scrypt 哈希，会话使用 HttpOnly、SameSite=Strict Cookie。

复制项目到另一台机器或备份时，停止服务后另外复制整个 `.data/` 目录，以保留玩家与收藏。可用 `PLAYER_DATA_DIR=/path/to/player-data npm run dev` 指定数据目录；同一目录只供一个服务进程使用。通过 HTTPS 反向代理运行时设置 `COOKIE_SECURE=1`。更新服务端代码后需重启 `npm run dev`，然后刷新浏览器。

首次启动自动创建管理员账号；也可在服务停止时运行 `npm run setup:admin` 提前创建。用户名通常为 `admin`；若已有同名普通玩家，则使用 `admin_2` 等名称，不会提升普通玩家权限。随机生成的初始密码和准确用户名保存在数据目录的 `admin-account.txt`，仅文件所有者可读，不会输出密码到日志或通过网页下载。此文件含登录凭据，应保密。后续启动和重复执行安装脚本不会改变已有管理员账号或密码。公开注册和档案编辑均不能授予管理员权限。

管理员通过普通玩家菜单登录，然后点击 **Server settings** 管理：

| 设置 | 默认值 | 范围／效果 |
| --- | --- | --- |
| Cached audio files limit | 384 | 0–10,000；降额后按最近访问时间清理旧 WAV，0 表示不保留音频文件 |
| Speech queue limit | 8 | 1–32；含当前任务，超出限制的新请求需稍后重试 |
| Enable spoken questions | 开启 | 关闭后不再接受新的朗读请求；已经播放或生成中的音频正常结束 |
| Allow new player profiles | 开启 | 关闭后禁止新建档案；已有账号仍可登录，游客仍可游戏 |

点击 **Save settings** 后服务端立即对新请求使用设置，并将设置与版本号保存在 `players.json`，重启后继续使用。音频清理排在现有合成任务之后，不中断它们；缓存清理失败会在状态面板和服务日志中提示。浏览器已经加载的音频可以继续播放。面板还显示缓存文件数、缓存体积、语音队列、账号数及运行时间。**Use defaults** 只填入默认值，需点击保存才生效；**Reload settings and status** 会替换未保存的表单。并发修改发生版本冲突时，需重新加载设置后再保存。

运行 `npm test` 检查数学规则、冒险造型、玩家隔离、管理员权限、配置持久化与校验、动态音频限制、宝物合并与重复请求、登录登出、重启后持久化、写入失败恢复、音频格式、语音缓存和播放取消。语音运行时和模型为 Apache-2.0，模型的来源及固定版本记录在 `voice-config.js`。
